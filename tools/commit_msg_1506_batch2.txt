content+engine: 1506 batch 2 - her level convention (a real defect), E3/E5, her speed trace, E6's amp

The batch found something bigger than the batch. The project pins a character's skill levels with ONE
level_convention rule, because a skill STARTS at level 1 and nothing else raises it - 63 of the other 94
characters carry one, and 1506 did not. So every number of hers was computed at Lv1: 战技 0.8 instead of 2.0,
强化普攻 1.2 instead of 3.36, 欢愉技·强化 0.45 instead of 1.125. Silent, because her judges read states and
counters rather than multipliers.

Shipped: p1506_level_convention (COMMON +9, the 15-row slots +14, which lands each slot on the last row of its
OWN table), p1506_e3_raises_skill_levels (SKILL+2, COMMON+1, ELATION_SKILL+1), p1506_e5_raises_skill_levels
(ULTRA+2, TALENT+2, ELATION_SKILL+1, ELATION_EXTRA+1), p1506_trace_speed_becomes_elation (Speed >= 160 ->
+50% 欢愉度), p1506_e6_amp_while_in_godmode (增笑 50% as ELATION_DAMAGE_AMP, the same word Pearl's uses).

Measured, and worth keeping:

  * the effective level is NOT Skill.getLevel() (a base that a rule does not move - every slot read 1 that way,
    and the rules looked broken); it is Canhit.skillLevel(skill), base plus raises clamped to the table length.
    That clamp also means E3/E5's increments CANNOT BE OBSERVED at full level: the convention already sits every
    slot on its cap, so +2 has nowhere to go. The judge pins that plainly instead of pretending to see it;
  * a raw base write (baseNoCompute) is overwritten when the battle starts - the unit read 119 however the base
    was set - so a fixture must apply a MODIFIER before startBattle();
  * percentBuff takes an additive share, not a rate.

Registered, not approximated: E3's four entries for 150608/150610/150612/150618 (the enhanced basic and its
盲盒 sub-skills) have nowhere to go, because the level vocabulary takes a SkillType name and those slots have
none - the same reason those slots cannot be pinned by the convention either. And the speed trace's second half
(「每超过 1 点速度 +2%，最多计入 100 点」) needs a scaling clamped at 100 points, which no spelling provides.
